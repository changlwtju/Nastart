安装

Nastart App 现在能下载吗？

目前为内部开发版（0.1.0），尚未上架 App Store。上架后，下载方式会在此页更新。

Nastart Agent 怎么装？

Nastart Agent 是运行在 NAS 或服务器上的增强服务。Docker 镜像为 changlwtju/nastart-agent（Docker Hub）。可通过 Docker Compose、群晖 SPK 或通用 Linux systemd 安装，默认端口为 8787。

Agent 需要什么配置？

需要一台能运行 Docker 的 NAS 或 Linux 主机。Agent 默认使用自签证书提供 HTTPS，App 配对时需打开「跳过 SSL 验证」。

配对与连接

怎么把 App 和 Agent 配对？

在 App 中进入「设备 → 配置 Nastart Agent」，地址填写 https://<NAS 地址>:8787。从 Agent 容器日志中找到一次性配对码并填入，确认已打开「跳过 SSL 验证」，再点「重新配对」。

配对码在哪里找？

查看 Agent 容器日志，在最新的 One-time pairing code: 条目后读取配对码。每个码只能用一次。

配对码提示无效怎么办？

配对码用过即失效。重启 Agent 容器后，在日志中查看是否生成了新码。日志出现新码时，用该码重新配对。

常见故障

App 显示 Agent 未连接怎么办？

先确认 Agent 容器在运行，地址和端口填写正确，且手机与 NAS 在同一局域网内，或所用的外网端口转发已连通。如果更换或重装 Agent 后配对失效，请用新码重新配对。

遇到证书 / SSL 提示怎么处理？

Agent 默认使用自签证书。App 配对时打开「跳过 SSL 验证」，首次连接时 App 会记住该证书的指纹。

在外网怎么连 Agent？

可在路由器上将外部 TCP 8787 转发到 NAS 的 8787 端口，然后在 App 中填写 https://<域名>:8787。也可使用 Tailscale 等 VPN，让 Agent 端口保持在私有网络内。

换了 NAS 或重装 Agent 后要重新配对吗？

Agent 身份发生变化时需要重新配对。App 会提示「Agent 已更换或配对已失效，请重新配对」，此时用新配对码重新配对即可。
