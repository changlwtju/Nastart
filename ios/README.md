# iOS

This directory is reserved for the future Nastart iOS/iPadOS app.

Recommended initial stack:

- Swift
- SwiftUI
- Swift Concurrency
- Observation
- URLSession
- Keychain
- CryptoKit
- Network.framework
- WidgetKit
- StoreKit 2
- OSLog

Do not create the final Xcode project until the first iOS architecture and PRD
are drafted, unless a prototype is needed earlier.
