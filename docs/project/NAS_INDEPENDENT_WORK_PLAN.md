## 竞品研究怎么落到改动

1. **Infuse：连接、文件夹和恢复操作。** 官方[媒体服务器指南](https://support.firecore.com/hc/en-us/articles/360006462093-Streaming-from-Plex-Emby-and-Jellyfin)区分连接/库、直接模式/本机库、扫描新内容与刷新资料，并按触摸/遥控提供不同入口。这可作为我方“操作含义相同、平台操作适配”的参照，不照搬整套选项。现有独立连接和原子编辑已实现，要补失败/重试、关联库和取消的完整体验，而非从零重做。
2. **文件视图与作品视图分开。** 官方[Smart Folders](https://support.firecore.com/hc/en-us/articles/23312095185815-Smart-Folders)解释按作品折叠文件夹的收益与浏览开销。可参照其信息组织思想，客户端聚合正片/光盘/多段，保留用户查看真实文件的入口；不采用任何改NAS文件名或目录的建议。
3. **网易爆米花：媒体展示。** 以既有历史真机图为起点，核海报/详情的层级、主要播放操作、资料缺失状态与返回位置；10-28手机只看到了升级提示、TV只列安装清单，不能称完整连接编辑流程已实看。本轮没有启动竞品，后续只观察不会自动访问旧NAS的页面。
4. **Shadowrocket：设置密度。** 用户指定的参考方向是分组、间距、分隔、状态及克制的强调色；本轮未重新实看其页面，不凭印象记版本或声称完成对照。观察时不改代理/VPN/账号。

每项参考记录“我方问题→同设备竞品操作→采用/不采用及理由→共用组件→验收”。不同来源的硬件/网络/版本证据不能混成性能排名；更多规则见[竞品矩阵](../testing/COMPETITOR-DEVICE-MATRIX.md)。

## 不需要NAS，但仍需真机的部分

电视焦点与返回、手机大字触控、Pad分屏/旋转、真正帧时间和内存、PiP、实际声音及HDR显示，可以用隔离本地素材在真机验证，并不必等NAS修复。执行前仍逐机fresh核身份、最新包、保留数据覆盖、原偏好和正常包；夹具参数/证据独立记录，结束恢复正常包，不触发旧NAS登录。iPhone18使用中不主动控制。

## 必须等NAS安全恢复的部分

真实WebDAV/SMB/FTP权限与服务器兼容性、DSM/Jellyfin新认证和实际路由、百GB影片的Wi-Fi/弱蜂窝首帧/续播/远距离seek/轨道响应、服务端兼容流与持续缓冲、跨设备真实索引/进度同步。这些不能用本地mock、模拟器或旧包升级成验收。本阶段114格不因离线逻辑/编译增加P。旧凭据/SID不自动复用；恢复后先核用户确认的新环境。
