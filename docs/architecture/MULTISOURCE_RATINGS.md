# 三端多来源评分接入调研

核对日期：2026-10-25。状态：接入方案，**不是已交付功能**。用户确认没有现成评分服务/插件，由项目继续调研；只借鉴 SenPlayer 的来源区分，不复制其布局。需求归入[唯一总账](../project/PLAYBACK_EXPERIENCE_PRIORITIES.md)的三端详情体验。

## 当前数据与结论

对当前 Jellyfin 10.11.11 进行只读元数据核对：112 部电影均有 IMDb、TMDB 条目 ID；没有 Douban ID、明确的豆瓣评分或已安装的豆瓣插件。当前客户端显示 `CommunityRating`，它不携带数据来源；存在 IMDb/TMDB/Douban ID 均不能证明这一个数来自对应平台。原始响应、插件列表及地址/凭据只留本机私有证据。

推荐将多来源评分放在独立的共享数据层，三端使用同一来源、量纲、影片匹配和缓存规则。优先评估 MDBList 的国际评分聚合，豆瓣保留独立适配。当前没有账户密钥，未完成任何外部评分服务的认证请求或三端真实评分验收；没有填入示例分数、伪造来源或改 NAS 配置。

## 候选与已核实边界

| 候选 | 已核实能力 | 对本项目的取舍 |
| --- | --- | --- |
| MDBList | [API 文档](https://api.mdblist.com/docs/)、[OpenAPI](https://api.mdblist.com/schema/)支持按 IMDb/TMDB 等 ID 查询，返回 ratings 数组；评分枚举含 IMDb、TMDB、Metacritic、tomatoes、audience 等。免费账户每日 1,000 次请求，需要 API key 或 OAuth。当前评分枚举没有豆瓣。 | 优先国际来源；不能宣传一次解决豆瓣。免费额度是账户共享，仍要缓存/合并请求。来源值、尺度和缺失策略须在有认证响应后验证。 |
| OMDb | [官方接口](https://www.omdbapi.com/)、[密钥申请](https://www.omdbapi.com/apikey.aspx)支持 IMDb ID 精确查找，免费每日 1,000 次；内容标注 CC BY-NC 4.0。 | 国际评分备选，不能因有 IMDb ID 便把 Jellyfin 通用分数冒充 IMDb。未核到豆瓣支持；不同时接两家造成无谓请求。 |
| Xzonn Jellyfin 豆瓣插件 | [作者说明](https://xzonn.top/posts/Jellyfin-Plugin-Douban.html)要求 10.11.x 用 4.x；当日清单有 4.4.3.0 / ABI 192.0.2.1。安装需重启 Jellyfin，采集依赖网页解析/限速。 | 仅兼容版本线成立，不等于当前环境安装/取分通过。源码 `MovieProvider.cs` 把豆瓣分数写入单一 `CommunityRating`，Controller 只有图片代理，不能仅安装插件便获得 IMDb、豆瓣两份独立分数。暂不推荐覆盖现有全库元数据。 |
| 有来源的本地 NFO/自有元数据 | 若实际文件保留独立命名评分，可作为数据输入。 | 当前未读取或验证现有 NFO 的评分，不能当已有来源。以后必须保留来源名与作品 ID，不能只读默认 rating 后猜来源。 |
| 豆瓣直接接口/网页 | 作者说明无公开 API，当前普通条目访问曾遇安全校验；[豆瓣数据声明](https://www.douban.com/about/legal)要求使用数据取得相应授权。 | 尚未确认可稳定接入的数据服务；不绕过校验、不索要用户 Cookie、不使用网上公开的他人密钥。产品化接入另核数据使用条件。 |

IMDb 官方也区分[授权数据与个人非商业数据集](https://help.imdb.com/article/imdb/general-information/can-i-use-imdb-data-in-my-software/G5JTRESSHJBBHTGX)，不采用直接抓取 IMDb 页面作为默认方案。

## 共享实现约束（待实施）

- 每条评分记录保存：来源、原始分数、原始量纲、评分人数（可缺失）、作品类型及外部 ID、获取时间、数据服务身份。IMDb/豆瓣/TMDB 各自展示，百分比保留百分比，不计算一个混合总分。
- 详情页使用紧凑的来源名称和数值条目，iPhone 自动换行，iPad/TV 随宽度排布；沿用本 App 字体、主题与焦点高亮。无真实评分则隐藏该来源，不显示 0 分或空占位。
- 优先以现有外部 ID 匹配；电视剧、季、集分开识别，不把整剧分数标成单集评分。标题/年份搜索只能返回待核匹配，不能静默采第一结果。
- 评分异步加载，不阻塞首页、详情内容、视频准备和起播；共享缓存与并发去重，失败退避，429 遵循 Retry-After。先展示有效缓存，过期策略依据服务条款与实际返回决定。
- DSM/Jellyfin 凭据不发送给评分服务；用户密钥仅本机安全保存，日志不包含密钥。没有外部账户时不发认证重试或要求登录豆瓣。

下一步依赖：选定国际来源并取得可用账号授权，先核真实返回的逐来源数据；豆瓣另确认来源及独立数据输出。之后再接共享组件与三端详情页，分别验收，不能把模型/演示截图当已安装评分功能。
