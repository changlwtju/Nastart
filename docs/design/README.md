# Design

This directory will contain Nastart design system, UX, icon, theme, and
prototype documents.

Planned files:

- `APP_ICON_DIRECTION.md` - first app icon concept direction and rejection rules
- `DESIGN_PRINCIPLES.md`
- `INFORMATION_ARCHITECTURE.md` - first navigation and screen structure
- `UI_STYLE_GUIDE.md` - app shell style, typography, colors, icons, and cards
- `UI_WORKFLOW.md` - required staged UI workflow from IA to real-device testing
- `MEDIA_SERVICE_FLOWS.md` - Jellyfin, Emby, Navidrome, media resource, and external handoff UX flows
- `LAUNCHPAD_THEME_STRATEGY.md` - quality-first launchpad theme strategy
- `wireframes/nastart-low-fi-wireframes.html` - first low-fidelity browser-viewable wireframe board
- `wireframes/nastart-launchpad-concept-wireframes.html` - launchpad-focused concept wireframes for distinct layout directions
- `LAUNCHPAD_DESIGN.md`
- `THEME_SYSTEM.md`
- `ICON_SYSTEM.md`
