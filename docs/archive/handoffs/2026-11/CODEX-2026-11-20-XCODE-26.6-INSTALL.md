# 2026-11-20 Xcode 26.6 安装与 iPhone 13 USB 识别

用户指定由 Codex 网页下载并安装 Xcode 26.6，作为 iPhone 13 更新的工具。接续 [iPhone 13 App 更新预检](CODEX-2026-11-20-IPHONE13-APP-UPDATE-FOCUS.md)。

- Safari 单独窗口打开 Apple Software Downloads，通过其中的 Xcode 26.6 Apple silicon 链接完成 2.32 GB 下载。直接访问 Apple CDN 返回 Unauthorized，经下载页的 Apple 入口成功。XIP SHA-256 `06384762f286fb4d20440f7a67ba40cdf79bedb1cbee9e5111e3030a53a6cb81`，`pkgutil --check-signature` 为 signed Apple Software。 [Apple 发布记录](https://developer.apple.com/news/releases/?id=06252026a)
- 首次解压因可用空间不足失败。从 Codex 本项目专用、无占用的 DerivedData 清理了可重建的 ModuleCache、Index 和编译中间件，可用空间由约 4.9 GiB 增到 9.0 GiB。保留源码、构建产物及原始证据。随后系统 `xip` 解压成功，App 深度验签及 Apple 锚点验证通过。
- 并排安装至 `/Applications/Xcode-26.6.app`。本机运行显示 Xcode 26.6 / 17F113，first-launch 状态检查退出码 0。系统默认路径仍为 `/Applications/Xcode.app/Contents/Developer`，对应 Xcode 27.2 / 27B52。
- 仅对 Xcode 26.6 的单次进程指定 `DEVELOPER_DIR`，`xcdevice` 读到 iPhone14,5 / iOS 16.3.1 (20D67)，`interface=usb, available=true`。本窗止于工具安装与 USB 识别，未申请新描述文件、未发送 Nastart 或 WDA 安装。下个设备窗口仍需核源码包与独占，完成同团队续签、备份、覆盖和启动验证。

无源码改动、网络设置改动或媒体实测。安装证据在先前私有批次的 `xcode-26.6-install-current.txt` 指向目录。设备和构建资源空闲。
