## 接受的隔离实现

DNS快照内最多8个规范化数字候选，按顺序逐个尝试；每个独占context，销毁并关闭后才进入下一个。原服务器名固定为UNC身份、数字地址仅传输；相同规范地址去重。保留总体剩余预算，并给认证开始前的候选单独较短预算（原型默认250ms，测试部分80ms），取消/总截止终止后续候选。

新增C进度回调在首次SESSION_SETUP入队前标记认证开始，Swift在该context记一次状态。只有该阶段之前的候选不可用才转下一个；进入认证后的拒绝、静默等待、权限/读取错误均直接结束，不向下一地址重复发起同组授权。标记的是请求入队，不能偷换成密码响应已送达；策略允许保守停止。源码本地参数/资源返回码等仍保留失败，不以成功回退覆盖所有C错误分类。

NativeSMBConnection默认可使用两族已解析快照，显式IPv4/IPv6入口保持；这是**有界顺序回退**，未实现并行Happy Eyeballs，也不保证快照已经包含今后所有DNS答案。回退不刷新/覆盖用户域名、不退回主机名同步解析、不改变签名政策，不自动重试密码或匿名账户。

固定C `aedafb2…`沿用4个有意修改文件，新增改动集中于connect_data认证进度和实验API参数；原C签名/帧/ERROR边界继续保留。完整差分、原型源码摘要和平台产物在私有证据，未签名/嵌入宿主。

## 最终验证

20个实际候选场景＋3个DNS集成窗口，不与旧批逻辑/服务/播放统计相加。

| 场景 | 结果 |
|---|---|
| IPv4、IPv6及跨族拒绝连接 | 首候选authStarted=false后转第二个，真实NFO读取成功；仅第二个认证 |
| 首地址不答协商 | 首连接只见108字节协商并关闭，测试80ms候选预算后第二个成功；本窗总107.326ms为本机测量，非NAS排名 |
| 首地址异常帧 | 认证前拒绝并转第二个，原签名政策保持 |
| 首地址成功 | 第二监听器未接受连接；重复地址仅1次尝试 |
| 规范认证拒绝 | 仅首地址NTLM握手，authenticationRejected，第二地址协商0 |
| 认证等待 | 进入SESSION_SETUP后不受80ms候选切换触发，按500ms总预算结束，实际505.079ms；第二协商0 |
| 目录权限拒绝 | 认证后权限错误直接返回，第二协商0 |
| 认证前/后取消 | marker证实实际协商/SESSION_SETUP已到服务端后取消，两窗各1候选；第二协商0，取消后15.102/12.480ms返回 |
| 180ms总截止 | 首候选等待实际199.232ms deadline，第二协商0；20ms轮询存在调度容差，不是硬实时截止 |
| 全部不可用/非法根 | 有限结束/立即拒绝，无认证或目录扫描 |
| 系统DNS到连接 | 两族实际读取成功；12个并发查询中6取消/6成功，SMB协商/关闭各6 |

所有成功窗仅读取50001字节NFO、目录中视频未READ，写请求0，逐窗源内容SHA/大小/名称/mtime/目录不变。正常服务peer关闭、静默模拟器已接受连接均见peerClosed；未使用的监听器在finally停止。NTLM一次握手含多个SESSION_SETUP包，不把包数当多次密码尝试。

ASan最终6个主要窗口/17个任务操作（5候选窗口＋12并发DNS任务），已核运行时和C socket/Swift RawReader插桩，未见失效访问或越界；非TSan、泄漏或穷尽竞态验收。测试端点均自有loopback，未取DSM凭据或改NAS/VPN/用户网络设置。
